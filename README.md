# GuardiaPro

**Bitácora digital, rondas e incidentes** para empresas de seguridad privada en Costa Rica.

## Funciones

| Módulo | Qué hace |
|--------|----------|
| **Bitácora oficial** | Inicio/fin turno, rondas, novedades, incidentes con GPS |
| **Puntos de ronda** | Checkpoints por sitio — un toque registra paso |
| **Fotos** | Incidente con foto desde el celular |
| **WhatsApp** | Alerta automática al supervisor en incidentes alta/crítica |
| **Programación** | Quién cubre qué sitio hoy |
| **Centro de control** | Turnos en curso, historial, incidentes |
| **PDF / imprimir** | Bitácora por turno para entregar al cliente |
| **Multi-empresa** | Panel Vendor crea empresas aisladas |
| **PWA** | Instalable en celular del oficial |
